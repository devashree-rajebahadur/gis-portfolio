Techniques in Image Interpretation & Remote Sensing

What I Have Learnt

Reflections on the main concepts covered throughout the course.

01

Interpreting topographic maps

I learnt how to access and interpret topographic maps prepared by Survey of India, including how to find out the toposheet number of a particular place, and understand map symbols. This is particularly useful for making use of historical maps.

Toposheets Map reading
02

Obtaining satellite imagery

I learnt how to download satellite images from various portals including Copernicus Dataspace Browser, USGS EarthExplorer, and Bhoonidhi. I also got to know how to filter the images according to my ROI, date range, and cloud cover. Knowing how to obtain satellite data is crucial for analyzing it.

Copernicus USGS Bhoonidhi
02

Making imagery composites

After downloading the satellite image, the next lesson was about creating image composites, by putting spectral bands in the three RGB channels, to visualize the image in different ways in order to highlight different features. For example, the NIR false color composite is used to inspect vegetation, whereas the SWIR false color composite is for water bodies.

False color composites
03

Visual interpretation of imagery

I learnt how to use photo recognition elements, such as tone, texture, shape, to recognise features in aerial and satellite images. When I was unsure about what a feature was, I used the method of ruling out all the possibilites, then narrowing it down to a few things that it could be, and then finally identifying it using the other features in this image, i.e. its context. This is a fundamental skill in image interpretation, and hence very important.

Photo recognition Interpretation
04

Registration of imagery

I georeferenced an historical toposheet to an imagery basemap of the same area using common features in both images; and later I repeated the same exercise but using aerial imagery instead of the toposheet. The georeferencing was much more accurate the second time since the image was high resolution and recently obtained. I learnt about the importance of accuracy in image to image registration.

Georeferencing
07

LULC mapping

In this exercise, I digitized all the different land use classes in a drone image to prepare an LULC map. A class number and hex code was assigned to each land use class to ensure consistency in the maps produced.

Digitization LULC
