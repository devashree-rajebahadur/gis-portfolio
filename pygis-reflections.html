Reflections on the main concepts covered throughout the course.

01

Python fundamentals

The first thing I learnt in this course was how to set up a code editor. I downloaded Visual Studio Code, cloned the ArcGIS Pro Python environment and set it up in VS Code in order to connect ArcGIS to it. Next, I learnt about data types, variables, functions in python, and how to perform operations on them.

Data types Variables
02

Describing data

In this exercise, I learnt how to describe a large dataset using .arcpy functions in python. Information about the data, such as number of features, etc. can be easily retrieved using a few lines of code, which makes it easy to obtain information about a large amount of data quickly.

Description
02

Running buffer and clip analysis

I created buffers of various distances around features and then clipped the underlying features to the extent of the buffer using arcpy.analysis functions. This was the first analysis operation I performed with python, so naturally it came with a lot of errors in the code, but I learnt how to understand and resolve the errors, and in the end it was very rewarding to see the output.

Buffer Clip
03

Automating analyses

I learnt how to automate the analyses performed in the previous exercise using for loops. So, the lengthy code that I had initially written was now reduced to just the initial workspace set up, variable assignment, and one for loop nested inside another. This is extremely useful for carrying out analysis on a large number of features, instead of writing individual codes for everything. It made me realise how important automation is in geospatial analysis.

Automation Loops
07

Automating map layouts

This exercise taught me how to create map layout using programming. This is particularly useful for creating reproducible maps. Once you have a customized and perfected layout, you can just change the input data to get similar maps.

Layouts

Assignment reflections

Buffer · Loops

Automated buffer analysis

I automated the process of creating buffers around places of worship in Chennai and clipping other features to its extent usigng for loops. The outer loop created the buffer at three distances, 100, 200, and 500 meters and the inner loop clipped the buildings, roads, railways, and waterbodies layer to the extent of the buffers.

12 output files were generated by writing a short piece of code, highlighting the important of automation in geospatial analysis.

Figure 1. Map layout of the buffers and clipped features around places of worship in Chennai, Tamil Nadu.

Overall Reflection

Since I did not have any prior programming experience, this course taught me everything right from the basics of python to conducting geospatial analysis with programming. I learnt to set up a code editor, an ArcGIS Pro python environment, a python interpreter, and then use different ArcPy functions for analysis. The key takeaway from this course for me is automation. I automated buffer analysis, geometry creation, map layout creation; manually doing all of these tasks would be time consuming, but automating them with python is very efficient.

I hope to further expand my programming skills and use them for advanced analysis and automation in my future projects.
